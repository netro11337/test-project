# Ozon Browser Automation Guide / Руководство браузерной автоматизации

## 🎯 Описание

Система полной автоматизации регистрации аккаунтов Озон через браузер Chrome с использованием MegaSMS для получения номеров телефонов и SMS кодов.

## 📋 Процесс регистрации

```
1. Получение номера телефона с MegaSMS
   ↓
2. Открытие https://www.ozon.ru/ в браузере Chrome
   ↓
3. Вход через номер телефона
   ↓
4. Озон пытается позвонить (ждем 30 сек)
   ↓
5. Нажимаем "Отправить код еще раз" для получения SMS
   ↓
6. Получаем SMS код с MegaSMS
   ↓
7. Вводим SMS код в браузер
   ↓
8. Переходим в профиль https://www.ozon.ru/ozonid
   ↓
9. Генерируем случайное ФИО (первое, отчество, фамилия)
   ↓
10. Генерируем случайную дату рождения (18-70 лет)
   ↓
11. Выбираем случайный пол (Мужской/Женский)
   ↓
12. Сохраняем профиль
   ↓
13. Добавляем email адрес
   ↓
14. Вводим код подтверждения с email
   ↓
15. Сохраняем
   ↓
16. Результат: номер:почта:пароль
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Запуск UI панели

```bash
python ozon_ui_panel.py
```

### 3. Настройка

- **API ключ MegaSMS**: Уже встроен (lpkfsipROdyEIHPv)
- **Количество аккаунтов**: Укажите в панели
- **Email адреса**: Введите в формате `email@example.com:пароль` (один на строку)

### 4. Запуск процесса

1. Нажимаем "Проверить баланс MegaSMS"
2. Вводим список email адресов (email:пароль)
3. Нажимаем "Начать"
4. Система будет регистрировать аккаунты автоматически

## 📊 Интерфейс панели

### Левая панель (Настройки):
- **Количество аккаунтов**: Сколько аккаунтов создать (1-100)
- **Список Email**: Email адреса с паролями
- **Кнопка "Загрузить из файла"**: Импорт email список из текстового файла
- **Кнопка "Начать"**: Запуск регистрации
- **Кнопка "Пауза"**: Временная остановка (активна во время процесса)
- **Кнопка "Стоп"**: Полная остановка (активна во время процесса)
- **Кнопка "Проверить баланс"**: Проверка баланса MegaSMS

### Правая панель (Результаты):
- **Таб "Логи"**: Полная информация о процессе (время, действия, ошибки)
- **Таб "Результаты"**: Успешно созданные аккаунты в формате номер:почта:пароль
- **Кнопка "Копировать результаты"**: Копировать все результаты в буфер обмена
- **Кнопка "Сохранить в файл"**: Сохранить результаты (текст или JSON)

### Прогресс бар:
- Отображает текущий прогресс (процент и количество обработанных/всего)

### Статус бар:
- Показывает текущее состояние системы

## 🔧 Использование в коде

### Простой пример:

```python
from megasms_service import MegaSMSService
from ozon_browser_automation import OzonBrowserAutomationSync
import asyncio

# Инициализация
sms_service = MegaSMSService("lpkfsipROdyEIHPv")
automation = OzonBrowserAutomationSync(headless=False)  # headless=True для фонового режима

# Инициализация браузера
automation.init_browser()

try:
    # Получаем номер телефона
    phone_data = sms_service.get_phone_number("ozon")
    phone = phone_data['phone']
    activation_id = phone_data['activation_id']

    # Получаем SMS код
    sms_code = sms_service.wait_for_sms(activation_id)

    # Регистрируем аккаунт
    success, message, result = automation.run_complete_workflow(
        phone=phone,
        sms_code=sms_code,
        email="user@example.com",
        email_password="password123"
    )

    if success:
        print(f"✓ Аккаунт создан: {result}")
    else:
        print(f"✗ Ошибка: {message}")

finally:
    automation.close_browser()
```

## 🐛 Решение проблем

### Браузер не открывается:
- Убедитесь, что Chromium установлен: `playwright install chromium`
- Проверьте, что Chrome установлен на компьютер

### SMS код не получается:
- Проверьте баланс MegaSMS (кнопка "Проверить баланс")
- Убедитесь, что API ключ правильный
- Проверьте лимиты MegaSMS (может быть ограничение по количеству SMS в день)

### Аккаунт не создается:
- Проверьте логи в левой панели
- Убедитесь, что вводите правильный формат email:пароль
- Может быть блокировка Озон (временная или по IP)

### Браузер закрывается:
- Система автоматически закрывает браузер после завершения
- Нажмите "Стоп" чтобы остановить процесс
- Проверьте логи на предмет ошибок

- Нажмите "Сохранить в файл" в правой панели

- Результаты будут в формате: номер:почта:пароль

### 3. Регулировка скорости:
В файле `ozon_browser_automation.py` можно изменить задержки:
```python
await page.wait_for_timeout(2000)  # 2 секунды
```

### 4. Headless режим:
Для запуска без отображения браузера:
```python
automation = OzonBrowserAutomationSync(headless=True)
```

## 📊 Статистика MegaSMS

### Стоимость:
- Средняя цена за SMS: 1-5 рублей
- Проверка баланса: бесплатно
- Отмена активации: бесплатно

### Лимиты:
- Максимум SMS в день: 100+ (зависит от аккаунта)
- Время жизни кода: 60 минут
- Время ожидания SMS: обычно 1-10 секунд

## 🔒 Безопасность

### Важные замечания:
- Система работает только с вашим браузером
- Никакие данные не передаются третьим лицам (кроме MegaSMS)
- Пароли от email не сохраняются локально
- Результаты хранятся только в памяти до сохранения

### Защита:
- API ключ MegaSMS должен быть приватным
- Результаты рекомендуется сохранять в защищенном месте
- Используйте VPN если нужно

## ❓ FAQ

**В: Что если я введу неправильный email/пароль?**
О: Система попытается добавить email с указанным паролем. Если пароль неверный, это вызовет ошибку при добавлении.

**В: Можно ли использовать прокси?**
О: Нет, система работает без прокси. Если вам нужен прокси для Озон - модифицируйте файл ozon_browser_automation.py.

**В: Есть ли возможность автоматических повторов при ошибке?**
О: Сейчас система просто пропускает ошибочные аккаунты. Можете добавить логику повтора в коде.

**В: Долго ли идет регистрация одного аккаунта?**
О: Обычно 3-5 минут на один аккаунт (зависит от скорости SMS, браузера и сервера Озон).
