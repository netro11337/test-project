# Ozon Авторегистрация - Быстрый Старт

## 🎯 Что это?

Полностью автоматическая система регистрации аккаунтов Озон через браузер Chrome с использованием MegaSMS для получения номеров телефонов.

**Результат работы**: номер:почта:пароль (один результат за одну строку)

## ⚡ За 5 минут до первого аккаунта

### 1. Установка (2 минуты)

```bash
# Установить Python пакеты
pip install -r requirements.txt

# Установить Chromium браузер
playwright install chromium
```

### 2. Запуск UI (30 секунд)

```bash
python run_ui.py
```

Откроется окно приложения.

### 3. Подготовка данных (2 минуты)

Создайте файл `emails.txt` с email адресами и паролями:

```
user1@gmail.com:password123
user2@mail.ru:password456
user3@yandex.com:password789
```

### 4. Запуск регистрации (1 клик)

1. В приложении нажимаем "Проверить баланс MegaSMS" ✓
2. Нажимаем "Загрузить из файла" и выбираем `emails.txt`
3. Указываем количество аккаунтов (например: 3)
4. Нажимаем "▶ Начать"
5. Смотрим логи в левой панели, результаты появляются в правой

## 📊 Подробный процесс каждого аккаунта

Для одного аккаунта система делает:

```
1️⃣  Получение номера с MegaSMS
2️⃣  Открытие https://www.ozon.ru/ в Chrome (инкогнито)
3️⃣  Ввод номера телефона
4️⃣  Ожидание 30 секунд (Озон пытается позвонить)
5️⃣  Нажатие "Отправить код еще раз" (получить SMS)
6️⃣  Получение SMS кода с MegaSMS
7️⃣  Ввод SMS кода в браузер
8️⃣  Переход в профиль https://www.ozon.ru/ozonid
9️⃣  Генерация и заполнение:
    - Имя (случайное, русское)
    - Отчество (случайное, русское)
    - Фамилия (случайная, русская)
    - Дата рождения (случайная, 18-70 лет)
    - Пол (случайный: Мужской или Женский)
🔟 Сохранение профиля
1️⃣1️⃣ Добавление email адреса
1️⃣2️⃣ Ввод кода подтверждения с email
1️⃣3️⃣ Завершение
1️⃣4️⃣ Результат: номер:почта:пароль
```

## 💡 Примеры использования

### Пример 1: Создать 5 аккаунтов

1. Создать файл `emails.txt`:
```
test1@gmail.com:pass123
test2@gmail.com:pass456
test3@gmail.com:pass789
test4@gmail.com:pass111
test5@gmail.com:pass222
```

2. Запустить: `python run_ui.py`
3. Загрузить файл
4. Нажать "Начать"
5. Ждать результаты

### Пример 2: Работа в коде

```python
from megasms_service import MegaSMSService
from ozon_browser_automation import OzonBrowserAutomationSync

# Инициализация
sms = MegaSMSService("lpkfsipROdyEIHPv")
browser = OzonBrowserAutomationSync(headless=False)
browser.init_browser()

# Получить номер
phone_data = sms.get_phone_number("ozon")
phone = phone_data['phone']

# Получить SMS код
code = sms.wait_for_sms(phone_data['activation_id'])

# Зарегистрировать
success, msg, result = browser.run_complete_workflow(
    phone, code, "user@mail.ru", "password123"
)

if success:
    print(result)  # +79101234567:user@mail.ru:password123
```

## 🔧 Если что-то не работает

### Браузер не открывается
```bash
# Переустановить Chromium
playwright install chromium --with-deps
```

### SMS код не получается
- Проверьте баланс в приложении (кнопка "Проверить баланс")
- Убедитесь что баланс > 0 рублей
- Проверьте логи - там будет точная ошибка

### Профиль не заполняется
- Озон может изменить структуру сайта
- Проверьте логи - там будет информация об ошибке
- Откройте issue с текстом ошибки

### Аккаунты не регистрируются
- Озон может блокировать по IP
- Попробуйте меньше аккаунтов
- Добавьте задержку между аккаунтами (в коде)

## 🔐 Безопасность

✅ Безопасно:
- Система работает через ваш браузер
- Данные не отправляются третьим лицам
- Каждый аккаунт в отдельном окне браузера (инкогнито)
- Никакие отпечатки не подменяются

- Использовать реальные данные
