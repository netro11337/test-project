# Ozon — параллельная сборка корзин

GUI на Python + Tkinter: задаёте число потоков, каждому потоку — свой список SKU.
Каждый поток работает в **отдельном браузере с отдельной сессией**, то есть
собирает **свою отдельную корзину**, и по завершении отдаёт ссылку на неё.

```
1 поток = 1 браузер = 1 сессия Ozon = 1 корзина = 1 ссылка
```

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Нужен установленный Chrome. Драйвер подтягивается автоматически
(`webdriver-manager`, с откатом на встроенный Selenium Manager).

## Как пользоваться

1. Укажите число потоков — под каждый появится вкладка «Поток N».
2. Вставьте SKU: в общее поле и нажмите **«Разбить по потокам»**, либо
   руками по вкладкам. Принимаются запятые, переносы строк, точки с запятой
   и полные ссылки вида `https://www.ozon.ru/product/tovar-1234567890/`.
3. **«Собрать корзины»** — в таблице справа видно живой статус каждого потока,
   в логе — каждый товар с временем.
4. По готовности: **«Копировать ссылку»**, **«Копировать все ссылки»** или
   **«Открыть корзину»** — поднимает видимый браузер именно с этой корзиной.

## Ссылка на корзину

Собрав корзину, поток открывает её и жмёт **«Поделиться корзиной»** — ту самую
кнопку на странице корзины. Полученная ссылка и попадает в таблицу; её можно
отправлять кому угодно, она не требует вашей сессии.

Ozon по этой кнопке ведёт себя двояко — то показывает окно со ссылкой, то
молча кладёт её в буфер обмена. Поэтому ссылка достаётся по очереди четырьмя
способами, первый сработавший выигрывает (`cart.py`):

| Способ | Что читаем |
|---|---|
| `input` | поле со ссылкой в открывшемся окне |
| `anchor` | `href` ссылки в этом окне |
| `text` | текст окна, если ссылка просто напечатана |
| `clipboard` | буфер обмена (права выдаются через CDP, перед кликом кладём метку, чтобы не принять за ссылку старое содержимое) |

Если не сработал ни один — в таблице появится **⚠** и обычный
`https://www.ozon.ru/cart`, а в логе будет причина. Корзина при этом собрана:
её видно кнопкой **«Открыть корзину»**, которая поднимает видимый Chrome на
профиле нужного потока (`~/.ozon_cart/profiles/thread-N`). Профили живут на
диске и переживают закрытие приложения.

Получение ссылки можно выключить чекбоксом **«Ссылка "Поделиться"»** — тогда
потоки не тратят на это время.

Если корзины нужны в вашем аккаунте Ozon, залогиньтесь один раз в каждом
профиле (кнопка «Открыть корзину» → вход) — сессия сохранится, и следующие
сборки пойдут уже в аккаунт.

## Оптимизации скорости

| Приём | Где |
|---|---|
| `--headless=new` | `driver.py` |
| Картинки, шрифты, видео отключены (флаг Blink + prefs + CDP `setBlockedURLs`) | `driver.py` |
| Аналитика/трекеры зарезаны по URL-маскам | `config.py` |
| `page_load_strategy = "eager"` — не ждём «хвост» загрузки | `driver.py` |
| Прямой переход `ozon.ru/product/{sku}/` вместо поиска | `worker.py` |
| Селекторы по `data-widget`, а не по классам | `worker.py` |
| Таймауты ≤ 5 с, опрос каждые 0.1 с | `config.py` |
| Единственный `sleep` — 0.35 с после подтверждения добавления | `worker.py` |
| С карточки сразу на карточку, без возврата на главную | `worker.py` |
| Пул потоков, драйвер живёт весь батч, а не поднимается на каждый SKU | `runner.py` |

Таймауты, паузу, число ретраев и параллельность можно менять прямо в шапке GUI.

## Исходы по каждому SKU

`added` · `already` (уже в корзине) · `out_of_stock` · `not_found` ·
`blocked` (антибот-проверка) · `error`.

Ретраи делаются только для `error` и `blocked` — исходы, которые могут
починиться при повторе. При `blocked` поток останавливается: проверка бьёт по
всей сессии, и дальнейшие попытки только копят ошибки, не портя другие корзины.

## Структура

```
main.py              точка входа
ozon_cart/
  config.py          настройки скорости, пути профилей, маски блокировки
  skus.py            разбор SKU и раскладка по потокам
  driver.py          фабрика Chrome со всеми оптимизациями
  worker.py          добавление одного SKU + распознавание исходов
  cart.py            страница корзины: подсчёт позиций и кнопка «Поделиться»
  runner.py          ThreadPoolExecutor, события в GUI, открытие корзины
  gui.py             Tkinter
tests/test_skus.py   тесты разбора и раскладки
tests/test_cart.py   тесты извлечения share-ссылки
```

```bash
python -m unittest discover -s tests
```

## Что стоит иметь в виду

- У Ozon есть антибот-защита. Много параллельных headless-сессий с одного IP
  повышают шанс поймать проверку — начните с 3–5 потоков и поднимайте, глядя
  на долю исходов `blocked`.
- Селекторы завязаны на текущую вёрстку Ozon (`data-widget="webAddToCart"`).
  Фронт магазина меняется — при массовых `Кнопка «В корзину» не найдена`
  правьте константы в начале `worker.py`, а при `Кнопка «Поделиться» не
  найдена` — в начале `cart.py`.
- Чтение буфера обмена в headless срабатывает не на всех сборках Chrome. Если
  ссылка стабильно не достаётся, снимите галку «Headless» — в видимом окне
  этот путь надёжнее.
- Chrome не даёт двум процессам держать один `user-data-dir`, поэтому
  «Открыть корзину» доступно только после остановки сборки.
